Step 1: Check Your Visited Breweries

This will read the visited breweries from your browser's localStorage.

Step 2: Download CSV for Google Sheet

Download a CSV file with all your visited breweries. You'll import this into your "cleaned" tab.

Step 3: Import to Google Sheet

In your Google Sheet:

  1. Open the "cleaned" tab
  2. Make sure you have "Visited" and "Visit_Date" columns (run "🚙 Add Visited Columns" from menu if not)
  3. Click File → Import → Upload
  4. Upload the CSV you just downloaded
  5. Import location: Replace data at selected cell
  6. Select cell A1
  7. ✓ Import data
